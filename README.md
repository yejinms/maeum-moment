# 마음의 순간

구체적인 연애 장면 속 두 행동을 비교해, 내가 사랑을 받을 때와 표현할 때의
상대적인 우선순위를 발견하는 모바일 우선 웹앱입니다.

## 핵심 경험

- 받는 사랑 20문항
- 표현하는 사랑 20문항
- 5개 행동 범주의 모든 조합을 두 번씩 비교
- 선택 확신도와 상황에 따른 응답 차이 반영
- 결과 순위, 두 트랙의 차이, 실제로 선택한 행동 카드
- 서버 전송 없이 브라우저에만 진행 상태 저장

이 결과는 심리 진단이나 관계 만족도 예측이 아니라 자기성찰과 대화를 위한
개인 내 상대 순위입니다.

## 실행

Python이 설치되어 있다면:

```bash
npm start
```

브라우저에서 <http://localhost:4173>을 엽니다.

## 테스트

```bash
npm test
```

## 구조

```text
index.html          앱 셸
css/styles.css      반응형 시각 디자인
js/data.js          40개 독자 문항과 범주 데이터
js/scoring.js       점수·순위·상황 의존성 계산
js/storage.js       로컬 상태 저장
js/app.js           화면 렌더링과 상호작용
tests/              데이터·점수 로직 테스트
docs/               PDCA 기획·설계·분석·보고
```

## 개인정보

MVP는 계정, 서버, 분석 도구를 사용하지 않습니다. 응답은 현재 브라우저의
`localStorage`에만 저장되며 결과 화면에서 직접 초기화할 수 있습니다.

## 지식재산 메모

공식 Five Love Languages 검사 문항, 결과 문구, 브랜드 에셋을 복제하거나
각색하지 않았습니다. 실제 출시 전 서비스명과 분류 표현에 관한 별도 검토가
필요합니다.
